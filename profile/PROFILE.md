# Profile kit: TikTok + Instagram

Profile picture: `profile-picture.png` (same picture on both).

## TikTok (fun_fact_for_real)

**Name** (max 30 characters):
```
Fun Facts For Real 🤯
```

**Bio** (max 80 characters):
```
3 crazy facts + a bonus, every day 🤯
New mind-blowing facts every day 👇
```

**Settings to check:**
- Keep it a **personal account** (Settings → Account → Account type). TikTok's Creator Rewards only pays personal accounts.
- Settings → Content preferences / Creator tools: turn on the **AI-generated content** label (the voice is AI).
- Once you have 3+ good videos: **pin your best 3** (open video → ⋯ → Pin).
- After 1,000 followers you can add a link in bio.

## Instagram (funfact_for_real)

**Name** (this field is searchable, so use keywords):
```
Fun Facts | Did You Know? 🤯
```

**Bio** (max 150 characters):
```
🤯 3 crazy facts + a bonus, every day
🌍 Animals • Space • History • Science
⏰ New Reels every day
👇 Which fact surprised you?
```

**Settings to check:**
- Account type: **Creator** (Settings → Account type and tools). Needed for posting through Zernio, and it gives you stats.
- Category: **Education** or **Digital creator**.
- Pin your best 3 Reels to the top of the grid (open Reel → ⋯ → Pin to your profile).
- Optional later: Story Highlights named **Animals**, **Space**, **History**, **Science**.

## Same name everywhere
Both accounts use the same picture and the same idea ("Fun Facts For Real"), so people recognize you on both apps.
